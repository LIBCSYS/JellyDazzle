# 188 — Plait Loom

A woven basket wrapped onto a logarithmic spiral. Two families of strands are
defined by u = A + B and v = A − B, where A = k·log r + drift and
B = n·θ/2π + spin; each family is therefore a set of logarithmic spirals of
opposite chirality, and they cross at every lattice cell. A strand exists where
|frac − ½| < halfwidth and is shaded as a cylinder, √(1 − (d/hw)²), so each ribbon
carries a lit crown and dark shoulders. Which ribbon is on top is decided the way
a real plait decides it — by the parity of (⌊u⌋ + ⌊v⌋), which alternates
over-under-over along every strand and makes the weave interlock rather than
merely overlap. n is even and the per-strand colour and glow phase are taken
modulo n, so the weave closes exactly around the θ seam with no visible join.
Edge softness is read from the true gradient |∇u|, which grows as 1/r, so the
ribbons antialias themselves as they crowd toward the middle and dissolve into a
dark core instead of aliasing. The radial drift pulls the whole plait inward
forever and the pattern is periodic in log r, so nothing ever restarts. Dark gaps
between ribbons keep roughly a third of the frame at zero. 218 fps, delta 1.16.
