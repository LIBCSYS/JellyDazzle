# 197 — Fern Dust

An iterated function system caught between four shapes. The chaos game — pick one of four
affine maps, apply it, plot the point, repeat — converges on the attractor of whichever
maps you used. Here all twenty-four coefficients are cross-faded between four complete
systems (Barnsley's fern, a branching leaf, a four-corner gasket and a rotating spiral) on
a smootherstep with a 40-second period and a shuffled visiting order, so the attractor
itself morphs; linear interpolation of contractive affine maps stays contractive, so no
interpolated state can diverge. Two details keep it from boiling. Each of the 100,000
points draws its map from a fixed uniform stream generated once, compared against
per-system probabilities that are themselves interpolated — so every point is a continuous
function of the coefficients and slides rather than flickers, while each system still gets
the |det|-proportional probabilities that sample it evenly. And the framing follows the
point cloud's bounding box through a 0.012 exponential filter, which absorbs the rare far
excursion instead of letting it jerk the zoom. Colour is by which map placed the point, so
the fern's stem, fronds and spirals separate. Splat weight is held at 0.028 so the dense
core of the invariant measure stays coloured instead of clipping to white. 224 fps, mean
frame delta 0.10, 87% near-black — overlay, and it reads as luminous dust rather than as
a diagram.
