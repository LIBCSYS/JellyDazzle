# 126 — Orbit Lace

A Julia set drawn by orbit trap rather than escape time. Each pixel iterates
`z <- z^2 + c`, but the colour is not how long escape took; it is how close the orbit
ever passed to a ring of radius rt about the origin, `trap = min_n | |z_n| - rt |`.
That single change is the whole idea: escape-time colouring fills solid basins and
produces a full-bleed field, while trapping paints only the thin locus of points whose
orbit grazed the ring — so identical mathematics yields nested filigree shells on
black, one shell per iteration index, threading through each other. The trap is
evaluated as `| |z|^2 - rt^2 | / 2rt`, a first-order form that avoids a square root
inside the loop. c walks the circle |c| = 0.745, just outside the main cardioid, where
Julia sets stay richly connected and vary continuously — so the lace re-knits and
never snaps between topologies, which is why the measured delta is 0.09, the lowest of
the set. The ring radius breathes on a second, much slower sine, and the view slowly
rotates and zooms. Hue is the iteration index at which the closest pass occurred, so
each shell takes its own place in the palette and the whole ornament reads as stacked
neon glass. 19 iterations at 512x384, bilinear-upscaled. Overlay-qualified
(83% near-black).
