# 141 — Chladni Sand

**Look.** Fine luminous filaments crawling over black, exactly like sand thrown on a
vibrating steel plate and shaken into the nodal lines: long shallow arcs that cross at
bright knots, loops that pinch shut and reopen, a scatter of grain along every thread.
Nothing else is lit — better than 90% of the frame is near-black, so it screens or maxes
straight over a ground layer.

**Math.** The nodal set of a square-plate standing wave,
`f(x,y) = cos(n pi x)cos(m pi y) - cos(m pi x)cos(n pi y)`, lit as `exp(-26|f|)`. The
trick that makes it a pattern rather than a still is that *n and m are driven
continuously* — `n1 = 3.4 + 2.6 sin(0.00119 t)`, `m1 = 5.1 + 3.1 sin(0.00083 t)` — so the
figure morphs smoothly through the whole mode family instead of cutting between integer
modes. A second, finer pair (`n2` around 6.7, `m2` around 9.3) is added at 55% weight so
the lace crosses itself. The expression is separable, so each frame builds four cosine
tables of width `w` and four of height `h`; the inner loop is two multiplies, an absolute
value and two table reads. A static 128x128 hash tile modulates brightness by ±25% and
supplies the grain. Colour is the palette walked by brightness plus a diagonal gradient;
the plate itself is a 9% palette wash.
