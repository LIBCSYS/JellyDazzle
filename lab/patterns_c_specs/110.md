# 110 — Firefly Sync

200 Kuramoto oscillators finding each other. Every firefly carries a phase and its own
natural frequency drawn from a narrow band around 0.0225 rad/frame (a ~4.6 s period);
each frame the swarm's order parameter `(r, ψ) = mean(e^{iθ})` is measured and every
phase is pulled toward it, `dθ_i = ω_i + K·r·sin(ψ − θ_i)` — the mean-field Kuramoto
model, O(N) per step rather than O(N²). The coupling K breathes slowly across the
critical value, so the swarm drifts in and out of coherence on its own: scattered
twinkling gathers into travelling waves of light, locks into a single collective
heartbeat where the whole field brightens and darkens together, then falls apart
again. Nobody scripts that transition — it is the model doing it, and it is different
every run because the phases are re-scattered per segment. Each fly is a 33 px radial
lantern glow whose flash is a raised cosine to the fifth power, about a second long
and never a strobe (mean frame-to-frame delta bottoms out at 0.01), with a floor so
nobody goes fully dark. Hue is set by each fly's natural frequency, so the fast and
slow flies read as different colour families until the swarm locks; when coherence
passes 0.35 a faint collective bloom washes the field in time with ψ. 67–98%
near-black.
