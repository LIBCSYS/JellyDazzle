# 102 — Vortex Silk

Seven point vortices stirring a sheet of tracer threads, integrated rather than
animated. Each vortex is carried by the flow of all the others,
`v(p) = Σ_j Γ_j (−Δy, Δx)/(|Δ|² + ε)`, which is the exact 2-D Euler solution for
point vorticity; that single line is why same-sign pairs orbit, opposite-sign pairs
translate like smoke rings, and triples fall into slow leapfrogging dances. A weak
central spring (0.0006 px/frame per px) keeps the ensemble on stage without visibly
biasing the dynamics. 1000 massless tracers ride the same field and write into an
accumulator that decays 2.3% a frame, so each one leaves a ~40-frame ribbon: the
flow draws itself. Ribbon brightness follows local speed — the slow far field falls
away and the fast collar around each core burns white — which turns the picture into
a map of the flow's energy instead of a uniform fur, and a rolling re-seed of seven
tracers a frame keeps the sheet supplied as threads spiral into the cores. Hue comes
from speed plus a per-tracer offset. The densest routine in this set (~50% near-black)
and the one that reads as a ground; motion is pure advection, so it is smooth by
construction.
