# 123 — Apollonian

The Apollonian gasket, drawn as rings of light on black. Three equal circles are
packed inside a unit disk (r = 2*sqrt(3) - 3) and Descartes' circle theorem is then
run as a reflection: for any tangent quadruple with curvatures b and centres z, the
*other* circle completing any three of them is `b' = 2(b1+b2+b3) - b4` with
`b'z' = 2(b1z1+b2z2+b3z3) - b4z4`, treating centres as complex numbers. Applying that
to each of the four slots and recursing generates the whole packing. The recursion is
run breadth-first rather than depth-first, which matters: BFS visits circles in
roughly increasing curvature, so a fixed 900-circle budget always spends itself on the
ones large enough to see instead of disappearing down one branch. Curvature is capped
at 155 (about 1.5 px at the render scale). The set is built once at init; every frame
only re-stamps outlines, so cost is the sum of the circumferences — roughly 25k soft
bilinear splats, not a per-pixel field, hence ~510 fps. Three concentric sub-rings at
+/-1.15 px give a soft 3 px line. The gasket rotates about a fifth of a degree per
second, breathes 2% in scale, and each recursion depth pulses on its own phase with
its own palette offset, so depth reads as colour. Overlay-qualified (93% near-black).
