# 179 — Harmonic Lantern

A spherical-harmonic surface drawn as glowing wire. The radius is Bourke's form
`r(theta,phi) = sin(a*theta)^p + cos(b*theta)^q + sin(c*phi)^u + cos(d*phi)^v` with all
exponents even, so r is never negative and needs no clamping. The form is **separable** —
the theta half depends only on the row and the phi half only on the column — so a 44x88
lattice costs 132 power evaluations per parameter set instead of 15,000, and the powers
themselves go through a binary `ipow` rather than `powf`. The lobes this produces are the
classic harmonic flowers: three- and six-pointed stars, quilted shells, spiky urchins.
The eight-integer parameter word crossfades between four presets every 760 frames, and as
in 176 it is the **vertices** that are interpolated, not the parameters — interpolating
integer exponents produces geometry that is neither of the two lanterns and usually a
mess. Every frame the lobe is normalised to a unit ball by its own measured `rmax` and then
projected, so a spiky preset and a fat preset are framed identically and the crossfade has
no size pump. Only latitude rings and meridians are drawn, additively, brightened by depth
and coloured by radius, so the shell is see-through and whatever is layered beneath it
shows through. 86% near-black, mean frame delta 0.26.
