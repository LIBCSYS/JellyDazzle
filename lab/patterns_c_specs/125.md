# 125 — Attractor Dust

A Clifford strange attractor, `x' = sin(a y) + c cos(a x)`, `y' = sin(b x) + d cos(b y)`,
rendered as a photographic long exposure. 200k iterates are splatted bilinearly into a
density field every frame with the four parameters creeping on four incommensurate
sines, so the filigree folds and unfolds rather than cutting. The design problem here
is shot noise: 200k points over ~40k occupied cells is four samples a cell, which
boils visibly. The fix is a one-pole temporal filter — `acc += (hit - acc) * 0.01`, a
~100-frame memory — which is both the noise solution and the look: it converts a
sparse point cloud into smooth smoke with genuine motion blur, and it holds the
frame-to-frame delta at 1.5 even though the underlying cloud is fully resampled every
frame. Two 1-2-1 separable blur passes remove the residual grain. Tone mapping is
Reinhard (`v = av/(1+av)`), not exponential saturation, because the dynamic range
between the caustic folds and the interior dust is enormous and exp() clips the folds
to flat white. Colour is the palette indexed by density, so the sparse outer dust and
the dense creases land in different parts of the ramp; a slow rotation and a palette
crawl keep it moving. Overlay-qualified (85% near-black).
