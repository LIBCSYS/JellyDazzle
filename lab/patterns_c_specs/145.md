# 145 — Aurora Curtains

**Look.** Six hanging sheets of airglow over a black star field: a wavy bright crown with
light hanging down from it in vertical rays, greens through blues into violet at the
fringe, everything sliding at a fraction of a pixel per frame. Bottom third of the frame
is empty sky, so it layers over anything.

**Math.** Curtain `c` is a top edge `yTop(x) = A + a1 sin(k1 x + w1 t) + a2 sin(k2 x - w2 t)`
with `a1` about 26–61 px and wavenumbers 0.013–0.048. Light hangs downward from that edge
with an exponential profile `exp(-u/L)` (L = 128–245 px) and a soft six-pixel leading edge
so the crown never reads as a drawn line. The ray structure is a third, higher-frequency
sine in x (k about 0.09–0.18) scrolling at its own rate and squared to sharpen it, so rays
visibly slide along the curtain. Depth below the edge walks the palette at 14 index units
per pixel, giving the crown/fringe colour split. Intensity and base height each ride their
own slow sinusoid. 220 static stars, no twinkle — nothing here changes faster than a few
tenths of a pixel per frame (measured delta 0.10). Rendered into a 480x360 float canvas
and bilinearly upscaled.
